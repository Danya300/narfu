

# 🏛 NARFU — Информационный портал объектов историко-архитектурного наследия

**NARFU** — это веб-приложение и CMS для учёта и популяризации объектов культурного наследия Архангельской области, разработанное для Северного (Арктического) федерального университета (САФУ). 

Проект представляет собой полнофункциональный портал с интерактивными картами, поддержкой 360° панорам, мультимедийным контентом и удобной административной панелью для контент-менеджеров.

---

## ✨ Основные возможности

- 🗺 **Интерактивная карта объектов:** Построена на Leaflet + OpenStreetMap с автоматической кластеризацией маркеров.
- 🖼 **Мультимедийные страницы:** Поддержка галерей, встроенных видео (YouTube, VK, RuTube), аудио-экскурсий и PDF-документов.
- 🥽 **360° Панорамы:** Интеграция Pannellum для просмотра сферических панорам с поддержкой WebGL.
- 🔄 **Слайдер «До / После»:** Интерактивное сравнение состояния объектов до и после реставрации (`img-comparison-slider`).
- ⚙️ **Гибкая CMS (Wagtail):** Использование `StreamField` позволяет собирать страницы из готовых блоков без участия программистов.
- 🔍 **Полнотекстовый поиск:** Быстрый поиск по заголовкам, описаниям, адресам и контенту с пагинацией.
- 📱 **Адаптивный дизайн (Mobile-First):** Корректное отображение на любых устройствах (Bootstrap 5), соответствие стандартам доступности WCAG 2.1 AA.
- 🎧 **Поддержка HTTP Range:** Кастомный Middleware обеспечивает корректную перемотку аудио и видео файлов в мобильных браузерах.
- 🐳 **Контейнеризация:** Готовый `Dockerfile` для развертывания. Легкий переход с SQLite (Dev) на PostgreSQL (Prod).

## 🚀 Установка и запуск

### Предварительные требования
- Python 3.12 или выше
- Установленный пакетный менеджер `uv` (рекомендуется) или `pip`
- Git

### Локальный запуск (Development)

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Danya300/narfu.git
cd narfu

# 2. Установите зависимости
uv sync
# Или через pip: pip install -r mysite/requirements.txt

# 3. Перейдите в рабочую директорию Django-проекта
cd mysite

# 4. Примените миграции базы данных
python manage.py migrate

# 5. Создайте суперпользователя для входа в админ-панель
python manage.py createsuperuser

# 6. Запустите сервер разработки
python manage.py runserver
# Альтернативно через Granian:
# granian --interface wsgi mysite.wsgi.application --host 0.0.0.0 --port 8000
```

🌐 **Сайт:** `http://localhost:8000/`  
🔒 **Админ-панель:** `http://localhost:8000/admin/`

### Запуск через Docker

```bash
# Сборка образа
docker build -t narfu-heritage ./mysite

# Запуск контейнера
docker run -p 8000:8000 -v $(pwd)/db.sqlite3:/app/db.sqlite3 narfu-heritage
```

## 🧪 Тестирование

### Unit-тесты
Проект содержит тесты для моделей, поиска и кастомного middleware.
```bash
cd mysite
python manage.py test
```
*Для проверки покрытия можно использовать пакет `coverage`.*

### Нагрузочное тестирование (Locust)
В корне проекта находится файл `locustfile.py` с эмуляцией поведения пользователей (просмотр главной, списка объектов, поиска).

```bash
# Запуск Locust
locust -f locustfile.py --host=http://localhost:8000
```
Откройте `http://localhost:8089` в браузере, задайте количество пользователей и запустите тест.

## 📂 Структура проекта

- **`mysite/`** — ядро Django-проекта (настройки `settings.py`, ASGI/WSGI, URLs).
  - **`home/`** — приложение с основными страницами CMS (Главная, О нас, Новости, Контакты, Партнёры, Эксперты) и сниппетами настроек (FooterSettings).
  - **`heritage_objects/`** — приложение для каталога объектов наследия (карточки, координаты, медиа-галереи).
  - **`search/`** — реализация полнотекстового поиска.
  - **`middleware.py`** — кастомный middleware для обработки `HTTP Range` (перемотка медиа).
- **`plantuml/`** — диаграммы архитектуры, классов и ER-диаграммы БД.
- **`locustfile.py`** — сценарии для нагрузочного тестирования.
- **`PROJECT_DOCUMENTATION.md`** — исчерпывающая техническая и пользовательская документация.

## 👨‍💻 Руководство контент-менеджера

1. Авторизуйтесь в Wagtail Admin: `/admin/`.
2. **Добавление объекта:** Перейдите в раздел *«Объекты»* → *«Добавить дочернюю страницу»*. Заполните метаданные (адрес, год постройки, стиль, координаты для карты).
3. **Конструктор страниц (StreamField):** Добавляйте блоки контента: *Заголовки, Параграфы, Изображения, Видео, 360° Панорамы, Документы, Сравнение (До/После)*.
4. **Настройки сайта:** В разделе *«Snippets»* можно глобально изменить контакты и ссылки на соцсети в *«Настройках футера»*.
5. Нажмите **«Опубликовать»**, и страница мгновенно появится на сайте.
